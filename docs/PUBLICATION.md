# 공개 자료와 제외 자료

이 저장소는 앱을 소개하고 구현을 살펴볼 수 있도록 정리한 공개용 소스 사본입니다.

## 포함한 자료

- 앱·위젯·공유 Swift 소스와 프로젝트 설정
- 단위·통합 테스트 및 합성 테스트 이미지
- 공식 테스트 광고 ID를 사용하는 Debug/QA 설정
- 운영 광고 ID를 비워 둔 Production 설정
- 앱 소개 README, 구조 설명, 공개 웹사이트·지원·정책 링크
- 검수한 한국어·영어·일본어 소개 이미지 36장과 소개 이미지 모음

## 포함하지 않은 자료

| 자료 | 처리 |
|---|---|
| 빌드·Archive·IPA·DerivedData·실행 로그 | 원래 작업 폴더에 보존하고 업로드에서 제외 |
| 인증서·개인키·배포 프로파일 | 업로드에서 제외 |
| 심사 연락처·계정 작업 기록·지원 문의 내역 | 내부 자료로 보존하고 업로드에서 제외 |
| 사용자 사진·일정·백업·저장소 파일 | 공개 자료에 포함하지 않음 |
| Xcode 개인 설정·사용자 상태 | 업로드에서 제외 |
| 실제 운영 광고 ID | 공개 사본에서는 제거; 관련 테스트는 가상 ID 사용 |
| 내부 Task 문서·기획 원본·사이트 배포 저장소 | 공개 저장소에서 제외 |

`.gitignore`는 검토한 경로만 포함하도록 구성했습니다. 새 자료를 추가할 때도 공개할 수 있는 내용인지 확인하고, 실제 운영 설정은 개인용 파일 또는 빌드 환경에서 주입하세요.

원래 앱의 출시 소스·광고 설정·서명 설정은 공개 사본을 만드는 과정에서 수정하지 않았습니다. 이 저장소의 공개와 App Store의 공개 출시는 별개입니다.
